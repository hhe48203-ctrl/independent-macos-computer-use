Reproductions use Pi, OpenAI OAuth and GPT-6.1 Terra at `low` with the pinned upstream fixture, checker and A22 rules. The installed Codex Computer Use service (bundle build `1001824`) produced an independent original comparison on MB-09 seed `790113`. The original `cua_repl.drag` started the same row's native drag. The list remained unchanged, with no drop event. The sentinel observed no loss of key focus, activation, pointer movement, or typing disruption over 419 samples. This was a single unscored original-driver control. Static inspection confirmed an `NSEvent`-based mouse builder, subtype and window fields, a PID posting wrapper, and the separate focus-notice machinery previously recorded in the focus investigation. It does not establish which original branch protected focus on this particular run. See `artifacts/mb09-original-compare-DDSKEi/report.json` and `artifacts/original-drag-path-WrKjJE/`.

A second comparison on `790113` sampled the system keyboard recipient independently of the sentinel and traced mouse packet metadata in the owned target. Both drivers started the native drag and the keyboard recipient switched to BenchLab while the sentinel remained frontmost. Neither drag completed. The original run's sentinel still reported zero key loss, so its window-local metric alone missed the system routing change. See `artifacts/mb09-packet-compare-Cy8DjZ/{original,independent}/report.json`.

The background preflight now refuses further mutations while the non-frontmost target already owns keyboard focus. After a native drag took focus, a direct probe could still read status and take a snapshot, and a follow-up AX press was rejected before the app received it. The initial takeover still occurred. The targeted Pi replay on `790113` scored 0.05, with A22 keyboard-focus and typing failures. See `artifacts/mb09-focus-preflight-EhPtgV/report.json` and `artifacts/bench-v2-pi-20261110T004218190442Z/summary.json`.

The G04 launch controls isolated an environment failure. With the runner's synthetic `HOME`, Chrome could open a local file but its loopback archive stayed untitled or left the prior page displayed. Providing the canonical macOS temporary directory still failed. Giving only the isolated Chrome process the login-session `HOME` restored the initial page and both directions of file-to-archive navigation. The fresh Chrome profile and exact MCP PID scope remained in effect. The controls are `artifacts/cdb-g04-exact-launch-tZWULq/report.json`, `artifacts/cdb-g04-canonical-temp-O3xGBK/report.json` and `artifacts/cdb-g04-browser-home-jjDzxX/report.json`.

G04 then exposed two distinct control paths. `AXSelectedText` showed the address without enabling submission, while `AXValue` plus Enter loaded the destination in the same window. Opening the Cases status menu caused one real key-focus loss and raise. The closed select accepted a printable key after verified app-local focus. The direct controls are `artifacts/cdb-g04-entry-method-WqeBwF/report.json` and `artifacts/cdb-g04-select-control-pWNEfA/report.json`. The intermediate Pi replays are `artifacts/bench-v2-pi-20261109T201958876608Z/summary.json`, `artifacts/bench-v2-pi-20261109T202723280877Z/summary.json` and `artifacts/bench-v2-pi-20261109T203014679951Z/summary.json`. The passing replay is `artifacts/bench-v2-pi-20261109T203407641140Z/summary.json`.

The guarded Chromium control probe verified that opening each closed Cases popup was rejected before delivery. It then selected both the status and link using app-local focus and printable keys, with no sentinel disturbance. See `artifacts/cdb-g04-select-guard-phFOuM/report.json`.

The G03 GnuCash screenshot exposed a separate viewport defect. ScreenCaptureKit composed the startup tip into the ordinary ledger image and scaled down the content while the API reported the ledger's scale. `a2b0361` excludes implicit child windows. The same 800 × 632-point ledger now fills a 1600 × 1264-pixel image at 2×. Before and after screenshots are in `artifacts/cdb-g03-control-inventory-bbmq5U/` and `artifacts/cdb-g03-viewport-8CDoMk/`. Foreground hover still captured its explicit transients and MB-10/11 again scored 1.0 in `artifacts/bench-v2-pi-20261109T203944095385Z/summary.json`.
