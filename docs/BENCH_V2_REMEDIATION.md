The G03 Calc probe on `99589` verified that an AX focus action selected the intended cell in the Name Box even though the cell continued to report `AXFocused=false`. F2 entered edit mode. A string AXValue write, a printable key and Enter left the cell empty. No disturbance was measured. The installed LibreOffice version's [cell focus implementation](https://github.com/LibreOffice/core/blob/libreoffice-26.8.2.2/sc/source/ui/Accessibility/AccessibleCell.cxx#L133-L146) moves the sheet cursor and its [text AXValue setter](https://github.com/LibreOffice/core/blob/libreoffice-26.8.2.2/vcl/osx/a11ytextwrapper.mm#L48-L53) has an empty implementation. A separate custom Unicode packet probe then returned `APP_GONE` before readback. It established no successful text insertion and the custom packet was not added to the server. See `artifacts/cdb-calc-focused-cell-7Q5uI6/report.json` and `artifacts/cdb-calc-editor-unicode-nkJhaN/report.json`.
