The list remained unchanged, with no drop event. The sentinel observed no loss of key focus, activation, pointer movement, or typing disruption over 419 samples. This was a single unscored original-driver control. Static inspection confirmed an `NSEvent`-based mouse builder, subtype and window fields, a PID posting wrapper, and the separate focus-notice machinery previously recorded in the focus investigation. It does not establish which original branch protected focus on this particular run. See `artifacts/mb09-original-compare-DDSKEi/report.json` and `artifacts/original-drag-path-WrKjJE/`.

The fresh Chrome profile and exact MCP PID scope remained in effect. The final Pi replay saw the archive page at launch but stopped after failing to submit the log URL through `typeText` and Enter. Checker 0.15, all eight A22 criteria satisfied.
